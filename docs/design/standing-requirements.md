# 长期需求台账（Standing requirements）

Status: 2026-10-27。这份文件记录用户在整个项目里反复表达、**不随单条消息失效**的
要求。每条注明来源；新消息只有在明确修改某条时才会覆盖它。设计/实现必须先对照
这里，再对照最新一条指令。

## A. 产品终态（用户 2026-10-27 明确）

1. **几乎完全自主的 Agent**：用户空闲时，它自己活动——玩手机、上网、自我开发、
   整理记忆、陪聊。
2. **交互以语音为主**：日常用语音；官方文字页面只在需要精确交互时使用（改代码、
   长文、审批、插件/设置）。
3. **角色始终在场**：默认界面是 Habitat（角色 + 语音），WebUI 是按需召唤的控制台。
4. **一个 Agent**：日常、开发、自主活动共享同一会话、记忆、身份。

## B. M10 的定位（用户 2026-10-27 澄清）

5. M10 **不是终态交付**，而是"让 Agent 能自主实现终态"的**地基**：
   自主循环、真实手机操作、控制台、自建插件、自升级、查资料、可观察、文档测试。
6. 判断 M10 完成看地基是否可用，不看语音对话是否自然。

## C. 交互与时段语义（用户 2026-10-26 起多次强调）

7. 首页把时钟替换为 **梁文峰（峰）/ 梁文谷（谷）+ 倒计时**。
8. 峰谷数据**必须从 tide 插件读取**，不得重造轮子；需要精确（含节假日）。
9. 调度分频：**峰段只跑轻量任务（C），谷段全力开发**。
10. 不允许"最小实现"；要按完整范围实现。

## D. 工程与复用（用户 2026-10-26/27）

11. **充分利用社区插件与官方页面**，不要重复造轮子；能复用就复用。
12. 官方 WebUI 嵌入客户端；文字页面是控制台，不是要重写的产品。
13. 并行实现要清理：同一能力只保留一条主路径，其余删除或降级为明确回退。
14. 每轮改动要验证、提交、推送 `agent/dev`；不推 main、不强推。
15. 不碰凭据、不上传、不购买、不静默安装（安装需确认）。

## E. 设备操作（2026-10-26/27）

16. 目标是用户不操作手机：截图、识别、点击、输入、装包、启动应用都由 Agent 完成。
17. 当前主路径：**手机内部 adb**（`127.0.0.1:5555`，无需 PC；重启后需一次外部 adb）。
18. 回退路径：无障碍 + MediaProjection（需一次性开启）。
19. root 不可行（华为锁 bootloader），不要在这上面浪费时间。
20. 不能声称"已帮用户打开某界面"；给路径/通知，让用户自己点。

## F. 运行与连续性（2026-10-26/27）

21. 重启后要能自动续跑（nudge 标记 + host 消费 + 外部兜底）。
22. 远程声音合成已接回（CPUFast `gpt-sovits-v2pro` / `silver-wolf`），保持可用。
23. 旧客户端已卸载；唯一客户端是 `local.sliverwolf.web`。
24. Stop That Shit 保持 watch-only，不主动上膛。

## G. 文档与决策

25. 设计文档要持续更新，反映真实实现与取舍，而不是一次性写完。
26. 设计要区分"终态参考"与"当前里程碑地基"，不要把终态当 M10 交付。

## 已知的未完成项（按地基优先级）

- 受控只读网络白名单 + 审计（自主轮现在不能查资料）。
- 自研 DSH 客户端插件脚手架（`@lumendsh/webui`）。
- 自主轮内构建 → 安装 → 重启的端到端验证。
- 重启后 adb/无障碍恢复流程。
- 活动时间线与失败可见性。
- 语音闭环（0.11 起，属于终态而非 M10）。


## H. 工作纪律（防绕圈）

来自 2026-10-27 的教训：为了修「自动续跑打断自主轮」，我连续改了 nudge、重启脚本、孤儿进程，
每修一次又制造新的自消息，形成自我指涉的循环，偏离了主线。

1. **一次只追一个根因**：修完若产生新的失败形态，停下记录，不立刻追下一个。
2. **自消息最小化**：不再用 nudge 维系连续开发；只有「重启后恢复」允许排一次，且运行中跳过。
3. **先问是否挡主线**：不挡主线的边界问题写进 self-note 或 backlog，不动手。
4. **时间盒**：同一问题超过 3 个回合没有用户可见进展，就停下来汇报，而不是继续加机制。
5. **用户可见优先**：优先做用户能直接感受到的功能（语音、界面、迁移），而不是调度器的边角。
6. **改完必验**：每个改动给出可复现证据；验证不了就说明验证边界，不声称完成。

## I. 停止信号

出现以下任一情况，立即停止当前方向并汇报：同一文件反复修改无进展、为修一个边界引入两个新边界、
需要不断给人造消息打补丁、用户指出「又绕圈了」。
