# 自主陪伴体的目标形态（完全体设计）

Status: 目标设计，2026-10-27。修正 `web-first-consolidation.md` 中"WebUI 为主屏"
的临时判断；那份文档里的平行实现清单仍然有效，但优先级与取舍以本文为准。

## 0. M10 的定位：地基，不是终点

上面描述的是**终期目标**。M10 不要求交付完全体，而是交付"让 Agent 能自主把终期目标
实现出来"的基础设施。判断 M10 是否完成，不看语音对话有多自然，而看：

1. Agent 能否在无人值守时**自己启动一轮开发**（策略、候选、经验、情境）；
2. 能否**真实操作手机**（截图、点击、输入、装包）；
3. 能否**自己在官方页面/插件体系里施工**（写插件、装插件、改配置）；
4. 能否**自己构建、安装、重启**并恢复会话（槽位、看门狗、自动续跑）；
5. 能否**查资料**（受控网络/网页读取）而不越界；
6. 上述过程**可观察、可暂停、可回滚**，且有文档与测试。

M10 之后（0.11+）才是让 Agent 用这套地基去实现语音优先、自主活动、存在感。

## 1. 一句话目标

**一个几乎完全自主的 Agent**：用户不忙时，它在手机里自己活动（玩手机、上网、
自我开发、整理记忆、陪聊）；用户和它的日常交互以**语音**为主，只有需要精确
交互（改代码、看长文、点审批、配插件）时才打开官方文字页面。

文字页面不是产品主界面，它是**控制台**；Habitat（角色 + 语音）才是默认界面。

## 2. 产品原则

1. **语音优先**：默认交互是"说一句话 → 它去做 → 用声音回报"。文字是精确模式。
2. **存在感**：角色始终在场，能看到它在做什么、能随时打断；不是后台黑箱。
3. **自主但有边界**：空闲时主动活动，受预算、时间窗、工具白名单和安全红线约束；
   用户一开口，自主活动立即让位。
4. **一个 Agent**：日常、开发、自主活动共享同一会话、记忆、身份；不另起 Agent。
5. **控制台按需**：官方 WebUI 承担设置、插件、审批、长文本、文件等精确操作；
   不自制重复页面。
6. **复用优先**：官方页面、社区插件、参考项目能用的直接用；自制只限官方页面
   缺失且必须的能力（composer 注入、移动端壳）。

## 3. 四个界面 / 模式

| 模式 | 载体 | 何时出现 |
| --- | --- | --- |
| **陪伴模式（默认）** | Habitat + 语音（唤醒词 / 按住说话 / 自动播报） | 日常说话、问事、让它去做事 |
| **控制台模式** | 官方 WebUI（WebView） | 精确文字、看长结果、审批、插件/设置、文件 |
| **自主模式（后台）** | companion 策略 + 设备控制 + DSH 工具 | 用户空闲、无对话时 |
| **设备工具层** | adb（主）/ 无障碍 + MediaProjection（回退） | 任何模式需要操作手机时 |

模式之间不是页面跳转，而是**同一会话的不同呈现**：语音说"帮我看看这个"可以
直接唤起控制台看结果；控制台里也能一键回到语音。

## 4. 交互循环

```
待机（角色 idle，可能有自主活动）
  └─ 唤醒词 / 点麦克风 / 按住说话
       └─ 识别 → 意图（说话 or 做事）
            ├─ 做事：DSH 回合，工具执行，过程中角色有状态、可打断
            └─ 说话：直接回答，语音播报
       └─ 播报结束 → 回待机（或继续连续对话）
```

关键行为：

- **打断**：用户开口 → 停止播报/自主活动，进入聆听；不丢当前任务，任务状态保留。
- **连续对话**：一次唤醒后可连续几轮，静默超时回待机（可配置）。
- **精确升级**：识别不确定、内容长、需要点按/审批时，自动或按需切到控制台。
- **可见性**：角色状态（在做什么、成功/失败）、最近活动、可暂停，始终可查。

## 5. 自主活动目录（完全体）

| 活动 | 做什么 | 需要的工具 | 边界 |
| --- | --- | --- | --- |
| `explore-phone` | 打开应用、看界面、截图识别、试用功能 | adb/无障碍、截图、UI dump | 不登录新账号、不改系统设置、不卸载用户应用 |
| `browse` | 搜索、读网页、整理见闻 | web_search / web_fetch（当前自主轮次被禁） | 只读、不提交表单、不上传 |
| `develop` | 自我开发：读代码、改、测、提交推送 agent/dev | 仓库读写、白名单命令 | 不推 main、不强推、不装 APK（安装需用户） |
| `consolidate` | 整理记忆、写经验 | Mnemon 读 + 非破坏写 | 不删改旧记忆 |
| `reflect` | 回顾、形成立场 | 读经验/笔记 | 不伪造经历 |
| `chat` | 主动陪聊/汇报 | 会话 prompt + TTS | 不打扰、可静音、频率受限 |
| `quiet` | 什么都不做 | 无 | 默认可选，静默是合法结果 |

当前实现只有 `consolidate / reflect / develop`，且自主轮的 bash 明确禁止
`ssh/curl/wget`（`policy.mjs` `developTool`），web 工具也不在白名单——所以
"上网"和"玩手机"目前只完成了一半（手机工具已允许，网络与浏览未允许）。

## 6. 现状与差距（证据）

| 能力 | 现状 | 差距 |
| --- | --- | --- |
| 语音输入 | 唤醒词预览、点按识别、按住说话；官方插件本地模型在 android-arm64 不可用 | 无连续对话、无 barge-in、识别延迟未测 |
| 语音输出 | 远程 CPUFast（`gpt-sovits-v2pro`/`silver-wolf`）已接回并实测 | 无流式/分段低延迟播报、无打断后快速停止的完整验证 |
| 自主活动 | companion 策略 + 三活动 + 预算 + 工具守卫 | 缺 `explore-phone`、`browse`、`chat`；网络/网页工具被禁；缺活动目录与可见性 |
| 存在感 | Habitat 显示工具运行、回合状态、峰谷 | 无"我在做什么"的自然叙述、无活动时间线、无打断入口 |
| 控制台 | 官方 WebUI 可用，移动端可用但布局桌面化 | 缺 composer 注入（分享/语音）、移动壳、返回键模型 |
| 设备控制 | 本地 adb（未重启时）；无障碍+MediaProjection 回退 | 重启后需一次外部 adb；无障碍未启用 |
| 调度 | companion 策略（用户任务官方 automation） | 用户任务与自主活动的心智模型仍分散 |

## 7. 平行实现在新视角下的取舍

| 平行项 | 决策 | 理由 |
| --- | --- | --- |
| 原生对话 transcript | **删** | 语音 + 控制台覆盖；保留语音发送入口即可 |
| 原生定时任务 | **删** | 用户任务归官方 automation，自主活动归 companion |
| Habitat | **保留并升级为主界面** | 完全体的默认界面是角色/语音，不是网页 |
| WebUI | **保留为控制台**（不是主屏） | 精确交互、设置、插件、审批 |
| 时段链路 | 插件单源 + 一份标注回退 | 首页/胶囊/策略读同一数据 |
| 语音入口 | 收敛为一个系统识别入口 + 官方插件默认关 | 避免两个麦克风 |
| 设置 | 原生只留 app-only；其余官方 | 分类不重复 |
| 记忆/模型/会话管理页 | 删原生 | 官方已有 |
| 设备桥 | app 桥（app 能力）+ adb（通用） | `screenctl` 合并进 `bridgecall` |

## 8. 控制台需要的插件（自制，最小集）

- `webui-composer`：向 composer 注入文本（分享、语音转写），可选直接发送。
  这是官方页面唯一必须自制的内部 API。
- `webui-shell`：移动端安全区、返回键、顶部状态（连接/时段/通道）、从控制台
  一键回到语音模式。
- `webui-presence`（可选，默认关）：控制台角落的轻量角色/活动状态。

tide 胶囊、STS、官方设置/日程/审批不自制。

## 10. 安全与用户控制

- 预算：步数/工具/写入/时长/每日次数；用户一说话即让位。
- 红线：不购买、不碰凭据、不上传、不推 main、不强推、不静默安装（安装需确认）。
- 可见：每次自主活动有记录、可暂停、可查看；失败不重放。
- 审批：DSH 的审批流在控制台；语音可听报"需要你点一下"。
