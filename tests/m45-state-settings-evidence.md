# M4.5 State and Presentation Increment

Version 0.4.9-m45-preview (16). Status: partial C02/C04/C05/C06 implementation;
not completion of F02/F05/F06/F07 or the M4.5 gate.

## Implemented

- Native HabitatState adapts whale-shota's 2600 ms completion hold. Real turn/tool/
  public text events select thinking/working/streaming/terminal presentation.
  Initial history is not celebrated; repeated reconciliation does not extend the
  hold. Offline is separate from failure. Decision/listening/speech own interaction.
- Bounded version-1 presentation settings persist independently of voice/appearance.
  Native editor exposes name, tag, size, bubble lifetime and preset lines. Colors are
  validated schema fields but not yet exposed in the form. Invalid values reject
  before storage. Existing profiles retain their pointers.
- Tap cycles explicitly labeled preset phrases through the existing attention queue;
  no prompt/model request is generated by this path. Source is visible in the text.
- Upstream sparse sway and visual rest/wake are adapted to visible time and attention.
  Idle rest after 90 seconds slows breathing/dims/tilts; interaction/task/voice wakes
  it. Backend execution is unaffected. This lifecycle code still needs duration-based
  device validation; compilation alone is not F06 acceptance.
